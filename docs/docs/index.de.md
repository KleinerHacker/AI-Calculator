# KI-Rechner

Der KI-Rechner ist ein kleiner Desktop-Rechner, entwickelt mit Kotlin und JavaFX
nach dem MVVM-Muster (mvvmfx).

Diese Dokumentation beschreibt den Rechner und die Bedienung seiner Oberfläche.

Im aktuellen Stand stellt die Anwendung ihre vorbereitete Basis bereit: ein
eigenständiges Hauptfenster mit einem aus dem Projekt-Logo abgeleiteten
Anwendungsicon. Die Rechenfunktionen werden hier dokumentiert, sobald sie
hinzugefügt werden.
