# AI-Calculator

AI-Calculator is a small desktop calculator built with Kotlin and JavaFX using the
MVVM pattern (mvvmfx).

This documentation describes the calculator and how to use its user interface.

At the current stage the application provides its prepared base: a standalone main
window with an application icon derived from the project logo. The calculation
features are documented here as they are added.
