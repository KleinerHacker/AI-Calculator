# AI-Calculator

AI-Calculator is a small desktop calculator built with Kotlin and JavaFX using the
MVVM pattern (mvvmfx).

This documentation describes the calculator and how to use its user interface.

At the current stage the application provides a standalone main window with an application
icon derived from the project logo, the keypad and the display, which shows the current
formula in small text and the permanently calculated result in large text. The calculator
evaluates the four basic arithmetic operations on arbitrary numbers; the keypad is not
connected to the display yet.
