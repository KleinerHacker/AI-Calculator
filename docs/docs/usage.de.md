# Bedienung der Oberfläche

Starten Sie die Anwendung über `./gradlew run`. Das Hauptfenster öffnet sich als
eigenständiges Fenster und zeigt das Anwendungsicon in Titel- und Taskleiste an.

Im aktuellen Stand ist das Fenster bewusst leer; Eingabeelemente und die
Ergebnisanzeige werden hier dokumentiert, sobald sie verfügbar sind.
